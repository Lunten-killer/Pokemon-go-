# Pokémon GO Events für Home Assistant

Inoffizielle Home-Assistant-Integration für Pokémon GO: Events als Kalender, Sensoren für Community Days, Rampenlicht- und Raid-Stunden, Raid-Bosse, Eier, Feldforschung und die offiziellen News.

Daten von [LeekDuck](https://leekduck.com) (über [ScrapedDuck](https://github.com/bigfoott/ScrapedDuck)) und [pokemongolive.com](https://pokemongolive.com/news). Kein Login oder API-Key nötig.

## Installation über HACS

1. HACS → ⋮ → **Benutzerdefinierte Repositories**
2. URL `https://github.com/Lunten-killer/Pokemon-go-` eintragen, Typ **Integration**
3. „Pokémon GO Events“ installieren und Home Assistant neu starten
4. **Einstellungen → Geräte & Dienste → Integration hinzufügen → „Pokémon GO“**

## Manuelle Installation

Den Ordner `custom_components/pokemon_go` nach `/config/custom_components/` kopieren und Home Assistant neu starten.

## Hinweis

Nicht mit Niantic, The Pokémon Company oder LeekDuck verbunden.
